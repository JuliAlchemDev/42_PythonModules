# Python Module 01 — Object-Oriented Garden Systems

## Exercises Overview

### Exercise 0: Planting Your First Seed

Introduces Python program structure and execution.

**Concepts**:
- Program entry point (`if __name__ == "__main__"`)
- Variables and basic data types
- Print formatting with f-strings

### Exercise 1: Garden Data Organizer

Learn to manage multiple objects using classes.

**Concepts:**
- Class definition and instantiation
- Instance attributes and methods

### Exercise 2: Plant Growth Simulator

Simulate plant growth over time by adding behaviors to the Plant class.

**Concepts:**
- Methods that modify object state
- Instance attributes and methods

### Exercise 3: Plant Factory

Streamline the plant creation process by instantiating multiple plants with varying characteristics.

**Concepts:**
- Object instantiation with initial parameters
- Creating multiple objects with different attributes

### Exercise 4: Garden Security System

Protect plant data through encapsulation and validation to ensure data integrity.

**Concepts:**
- Data encapsulation with protected attributes (_attribute)
- Getter and setter methods for controlled access
- Input validation and error handling

### Exercise 5: Specialized Plant Types

Handle different plant types by using inheritance to share common features and specialize behavior.

**Concepts:**
- Inheritance and parent-child class relationships
- Method overriding with super()
- Specialized attributes for different plant types

### Exercise 6: Garden Analytics

Implement advanced OOP patterns including static/class methods, nested classes, and multi-level inheritance for complex data tracking.

**Concepts:**
- Static methods and class methods
- Nested classes for encapsulation
- Multi-level inheritance chains
- Statistical data tracking
