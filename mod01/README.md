# Python Module 01 — Object-Oriented Garden Systems

## Exercises Overview

### Exercise 0: Planting Your First Seed

Introduces Python program structure and execution.

**Concepts**:
- Program entry point (`if __name__ == "__main__"`)
- Variables and basic data types
- Print formatting with f-strings

### Exercise 1: Garden Data Organizer

Learn to manage multiple objects using classes.

**Concepts:**
- Class definition and instantiation
- Instance attributes and methods

### Exercise 2: Plant Growth Simulator

Simulate plant growth over time by adding behaviors to the Plant class.

**Concepts:**
- Methods that modify object state
- Instance attributes and methods

### Exercise 3: Plant Factory

Streamline the plant creation process by instantiating multiple plants with varying characteristics.

**Concepts:**
- Object instantiation with initial parameters
- Creating multiple objects with different attributes
